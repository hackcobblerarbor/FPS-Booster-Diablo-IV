## Features

- **Graphics Configuration Presets** – Pre‑tuned settings for optimal FPS:
  - **Shadows** – Set to **Medium** for a solid performance boost; High/Ultra provide minimal visual benefit for the performance cost.
  - **Anti-Aliasing** – **DLSS/FSR** recommended over native AA for better performance and image quality.
  - **Texture Quality** – **High** recommended if you have 6GB+ VRAM (minimal FPS impact, mostly memory usage).
  - **Fog Quality** – Lowering to **Medium** saves GPU resources without breaking atmosphere.
  - **Clutter Density** – Reduce to **Medium** or **Low** for a significant CPU performance gain in open-world areas.
- **Upscaling Profiles (DLSS / FSR / XeSS)** – Pre‑configured profiles for NVIDIA DLSS, AMD FSR, and Intel XeSS with Quality and Performance mode presets for significant FPS gains (**+30-50%**).

- **GPU Tuning Presets** – Optimized graphics card settings for Diablo IV, including NVIDIA Reflex set to 'On + Boost' (where supported) to reduce system latency.
- **Display Optimization** – Fullscreen mode activation, V‑Sync disabled, and FPS cap recommendations (3 FPS below monitor refresh rate) for smoother frame pacing.

- **Memory and Storage Optimizations** – RAM management tweaks and pagefile adjustments for faster loading times and reduced stutter.
